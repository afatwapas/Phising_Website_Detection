This project analyzes the dataset to build a model to identify Phising Websites.
This project creates a Logistic Regression and Random Forest classifier model.

A complete end to end ML pipeline was made. It includes Data ingestion, data preprocessing using ETL, feature extraction, model training and testing.

Libraries Used- Pandas, numpy, matplotlib, seaborn, scikit-learn


Files in project:

Phising_Legitimate_Full: Dataset
url_detection: Jupyter Notebook containing data analysis and model training
